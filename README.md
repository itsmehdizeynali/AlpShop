# Resume Dashboard

This project is a dashboard built to showcase my technical skills as part of my resume/portfolio.

## Tech Stack

- Frontend: Next.js, TypeScript, Tailwind CSS
- Database: Prisma
- Backend: The backend of this project was developed with the help of AI assistance. I want to be transparent that I don't yet have full mastery over every detail of this part, and I'm actively working on deepening my understanding of it.

## A Note on Git History

Git has been active on this project since its inception, and it went through many commits during development. Unfortunately, due to technical issues (large file sizes in the commit history), I wasn't able to push the full commit history to GitHub.

That said:

# or
